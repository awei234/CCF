## 写作硬指标（SAR 高分画像，F01 校验）

- 词数 ≥ 4,000
- 图 ≥ 4 张、表 ≥ 6 张（数据可追溯）
- 必须含复杂度分析
- 结构完整：Abstract / Intro / Method / Experiments / Discussion / Conclusion / Related Work
- 引用 25-40 篇（在线可核验）

## 主题方向（从 01_方向库/T_论文主题 选）

- 主主题：T03 Agent 自演进 或 T04 实验严谨性（见对应 README 的叙事模板）
