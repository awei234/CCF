# Abstract

Presents a verification architecture in which a candidate solution is rewritten into typed state transitions, each licensed by an explicit justification (citation, computation, or problem-given fact), with completeness of change as the foundational invariant so hidden premises surface as unlicensed mutations. On HLE-Verified Gold certifies 105 problems at 91.4% strict precision; on 95 adversarial poisoned proofs, structured judges catch 94.7% vs 83.2% for holistic judging, with the gap concentrated in hidden premises (90.6% vs 62.5%) and fabricated citations (100% vs 90%).
