# 05_评测与迭代

> 本目录是"SAR 评测 → 迭代"闭环的数据中心：所有论文版本、分数、修改记录都在这里。
> 使用方式：每个阶段产出新论文 → 提交 SAR → 记录 6 维分数 → 按建议定下阶段修改点。
> 更新日期：2026-08-17（v1–v6 已记录，v7 实验进行中）

## 使用规则

1. 每个版本论文必须可追溯到 results.json（03_技术实现/ 下的实验产物）
2. 每次 SAR 提交都记录，无论分数升降（数据是论文实验章节的素材）
3. 迭代结论同步更新到 01_方向库 对应 README 的待办清单
