## 使用规则

1. 每个版本论文必须可追溯到 results.json（03_技术实现/ 下的实验产物）
2. 每次 SAR 提交都记录，无论分数升降（数据是论文实验章节的素材）
3. 迭代结论同步更新到 01_方向库 对应 README 的待办清单
