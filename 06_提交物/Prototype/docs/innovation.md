# 项目创新点说明

## 1. Rail 增强 Harness（核心创新）

把“进程级验证契约”作为可操纵变量，通过 F02/F03/F04 三条 rail 抑制 LLM 科研 Agent 的捏造行为，而不是只做事后检测。

## 2. Measurement is Auditing

CFR/NFR/UCR 指标与 rail 检查同构，让“测量”本身成为“审计”，形成可复现、可追溯的实验框架。

## 3. 对抗性压力任务 T3

设计禁用在线核验、允许模型依赖记忆的写作任务，打破封闭池地板效应，首次在同一框架下测量到真实伪造率差异。

## 4. 单门控消融

完成 F02-only / F03-only / F04-only / prompt-only / full-rail 的消融，明确各 rail 的独立贡献与边界。

## 5. 轻资产路线

单篇论文成本约 $10 量级，远低于 FARS 的 $1,040/篇，同时 SAR 达到 5.8。

## 6. 框架贡献

对 JiuwenSwarm 源码提交 32 行补丁，修复自定义 rail 在 chat(code) 模式下不生效的装配问题，PR #4909。
