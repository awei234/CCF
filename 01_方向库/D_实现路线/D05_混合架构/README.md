## 1. 方向定义

把前四个方向的优点组合成一套完整的参赛系统：

```
┌─────────────────────────────────────────────────────┐
│          科研流水线（D01 skill 提供流程脚本）           │
│  选题拆解 → 文献调研 → 方法设计 → 论文撰写 → 结果分析    │
└──────────────────────┬──────────────────────────────┘
                       │ 全程由 Rail 管控
        ┌──────────────▼──────────────┐
        │   Harness 层（D03 自定义 rail）│
        │  F02 实验严谨 │ F03 结果一致   │
        │  F04 引用核验 │ F01 写作质量   │
        └──────────────┬──────────────┘
                       │ 观察/评估自身表现
        ┌──────────────▼──────────────┐
        │   Auto Harness 层（D04 自演进）│
        │  改进 rail → 热加载/PR → 再验证 │
        └──────────────────────────────┘
```

**一句话**：D01 提供"会干活"，D03 提供"按规矩干活"，D04 提供"越干越好"，D02 按需提供"人多力量大"。

## 2. 为什么选（这是最终形态）

- 每一层都对应论文的一个章节/实验：D01=系统框架、D03=核心方法（rail scaffold）、D04=自演进实验、F02/03/04=严谨性实验
- 完整覆盖四维评分（方法/实验/创新/写作）
- 框架贡献素材最丰富（rail + 文档 + PR）
- 论文主题 T03/T04 都被它支撑
