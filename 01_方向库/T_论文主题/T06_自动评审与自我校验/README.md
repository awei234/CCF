# T06 自动评审与自我校验（论文主题）

## 1. 主题定义

研究 Agent 的**自动评审/自我校验**机制：让 Agent 在写作后自查（数字一致性、引用核验、结构完整性），或引入 LLM-as-a-Judge 评审流水线提升论文质量。这是 SAR（Stanford Agentic Reviewer）的核心思想的应用。

## 2. 为什么选

- **与我们每天用 SAR 评测的工作流天然融合**：SAR 就是评审 Agent，我们的自我校验 rail 就是轻量版评审 Agent
- 可研究"自评-修正循环"对论文质量的增益（FARS 论文 §6 未来方向："自动评审需要人类校准"）
- 实验数据现成：每次 SAR 提交就是一次评审样本

## 3. 论文角度

- 作为 T03/T04 的**辅助实验**：Agent 自评（六维自查）→ 修正 → 再评，测 SAR 提升
- 或作为独立主题：研究评审 Agent 的校准、区分度、与人类评审的相关性（对照 arXiv 2605.19156 的数据）

## 4. 实验设计建议

| 实验 | 内容 |
|---|---|
| 自评修正 | 无自评 vs 自评一轮 vs 自评两轮的 SAR 提升 |
| 评审校准 | 我们的自评 rail 与 SAR 的一致性（可对照文献中 SAR vs 人类 0.42 相关）|

## 5. 风险与劣势

- 与 SAR 评分本身"共谋"的风险：自评 rail 若过度拟合 SAR 风格，论文质量可能虚高（这也正是文献指出的 SAR 局限）
- 作为独立主题创新性中等

## 6. 与主线的关系

- **主要作为辅助实验**（自我校验 rail 的一部分：F01 写作质量 Rail 里的自查环节）
- 支持 S 组策略（每日 A/B 实验闭环）
