# T02 Agent 记忆引擎（论文主题）

## 1. 主题定义

研究 Agent 的长期记忆机制（存取、遗忘、检索、跨项目复用），支撑自动科研中的"跨论文知识积累"。官方建议主题之一："Agent 记忆引擎设计"。

## 2. 为什么选

- **官方建议主题**，新颖度中上
- JiuwenSwarm 自带记忆能力（`common/auto_memory/`、`common/memory/`、CodingMemory）可作为实验底座
- 与 FARS 架构契合：FARS 用"共享文件系统当记忆"——可对比验证记忆引擎的增益

## 3. 实验设计建议

| 实验 | 内容 |
|---|---|
| 基线 | 无记忆 vs 文件系统记忆（FARS 式）vs 记忆引擎（本项目）|
| 指标 | 多轮论文生成的 SAR 分 / Token 复用率 / 检索准确率 |
| 场景 | 连续生成 5+ 篇相关主题论文，测记忆带来的提升 |

## 4. 风险与劣势

- 记忆效果难量化，实验设计需谨慎（SAR 是论文质量分，不直接测记忆）
- 需要较长的多轮实验时间

## 5. 与主线的关系

- 可作为 T03/T04 主主题之外的**第二个实验章节**（记忆对科研流水线的影响）
- 或作为备选主主题（若 T03 时间不够）
