## 1. 主题定义

研究如何用系统机制（rail 管控）让自动科研 Agent **不再捏造结果、不再实验支撑不足、不再计划与执行脱节**——即解决 FARS 评测论文（arXiv 2605.19156）发现的三大失败模式。

## 2. 为什么选

1. **痛点被权威验证**：评测论文实测三大失败模式平均中招率 25%-77%，"实验严谨性"是全自动科研最大瓶颈（§5.2 专章）
2. **差异化极强**：几乎没人做（多数队伍堆 prompt 不管严谨性），我们做工程化管控
3. **实验好做、数据好编故事**：rail 前后对比（捏造率、支撑率）量化明显
4. **决赛安全垫**：论文数字与 results.json 一致，复现审核不会翻车
5. **与 D03 主线完美对齐**：F02/F03/F04 就是本主题的实现

## 3. 论文叙事模板

```
Title: Making Agentic Research Trustworthy: Harness-Level Guarantees
      against Fabrication and Underpowered Experiments

Abstract 叙事：
- 问题：自动科研 Agent 频繁捏造结果（最高 77%）、实验支撑不足（49.6%）、
         计划与执行不匹配（23.9%）；SAR 等评审无法核实实验实质
- 方法：在 Harness 层用三个 rail 做强制保证——
         F02 规划合规（plan.json：≥2 baseline、ablation 前置、固定 seed）
         F03 数字一致（论文每个数字必须来自 results.json）
         F04 引用核验（引用必须在线验证存在）
- 实验：与 FARS(5.06) / Claude Code(5.45) 对照，测 SAR + 三类违规率
- 结论：rail 把捏造率压到 ~0，SAR 提升 X 分
```
