# T01 Agent 上下文工程（论文主题）

> 分组：T 论文主题 ｜ 新颖度 ★★★ ｜ 实现门槛 低 ｜ 推荐度 ★★★
> 状态：备选主题（阶段 1 可用它先出基线论文）｜ 更新日期：2026-08-11

---

## 1. 主题定义

研究 Agent 的上下文（context）如何组装、压缩、调度，以提升长任务（如自动科研）的质量与成本效率。官方建议主题之一："Agent 上下文工程设计"。

## 2. 为什么选

- **最容易做对**：不依赖复杂实验环境，可针对"科研场景的上下文组装策略"做小实验（如上下文裁剪、记忆分层）
- **官方建议主题**：评委认可度有保障
- **阶段 1 基线首选**：作为第一篇论文主题，尽快出分

## 3. 实验设计建议

| 实验 | 内容 |
|---|---|
| 基线 | 完整上下文 vs 压缩上下文 vs 分层记忆上下文的论文质量对比（用 SAR 打分）|
| 指标 | 论文 SAR 分 / Token 消耗 / 完成率 |
| 消融 | 去掉上下文压缩 / 去掉记忆层 |

## 4. 风险与劣势

- 该方向被研究较多，**新颖度一般**，创新性（25%）维度难拿高分
- 纯上下文工程叙事与"改 rail"主线的契合度中等

## 5. 与主线的关系

- 主主题是 T03/T04 时，T01 可作为论文的 **Related Work 素材** 或一个辅助实验
- 作为阶段 1 基线主题：✅ 用它先拿分，后续主题再升级
