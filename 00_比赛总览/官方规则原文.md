## 1. 赛题基本信息

- **赛题全名**：【华为 openJiuwen】基于 JiuwenSwarm 的 Agent 科研论文自动生成
- **赛题副标题**：基于 JiuwenSwarm 的 Agent 科研论文自动生成赛题，由华为 openJiuwen 开源 AI Agent 社区出题，依托自研蜂群智能体架构，聚焦 Agent 前沿技术方向

- **报名平台**：中科息壤（xir.cn）

- **赛期**：2026-06-22 至 2026-10-31

## 2. 赛题任务（原文摘录）

> 开发智能体，完成比赛方指定 Agent 方向的科研短论文（Short Paper）**全流程/半流程自动化生成**，覆盖：
> **选题拆解 → 文献调研 → 方法设计 → 论文撰写 → 结果分析**
> 输出符合学术规范的完整论文，建议以 **ICLR 模板** 生成论文，以便使用 **Stanford Agentic Reviewer** 平台进行论文自动化评测。

**建议赛题主题（聚焦 Agent 关键技术）：**
1. Agent 上下文工程设计
2. Agent 记忆引擎设计
3. Agent 自演进

**参考标杆**：Analemma 打造的 **FARS（Fully Automated Research System，全自动研究系统）**
- 228 小时无人干预运行、产出 100 篇短论文（平均每篇 1.14 亿 Token、约 $1,000 成本、SAR 平均 5.05/10 分，高于 ICLR 2026 人类投稿均值 4.21 分）
- 官方列举 FARS 4 大局限（作为参赛者优化方向）：
  1. 算力利用率低（1.14 亿 Token/篇）
  2. 研究创新性不足
  3. 机制洞察深度欠缺
  4. 复杂假设筛选能力弱

## 4. 评分规则

**初赛自动化打分（核心）**：
- 提交论文至 **Stanford Agentic Reviewer**（paperreview.ai）获取 0–10 分总评分
- 大赛折算：**自动化得分 = Agentic Reviewer 评分 × 4**（满分 40 分）

**Agentic Reviewer 六大评审维度及权重**：

| 维度 | 评估要点 | 权重 | 折算分 |
|---|---|---|---|
| 研究重要性 | 问题价值、领域贡献、应用前景 | 20% | 8 分 |
| 原创性/创新性 | 与现有工作差异、新方法/新视角 | 25% | 10 分 |
| 方法合理性 | 方案可行性、逻辑严谨性、实现细节 | 20% | 8 分 |
| 实验严谨性 | 实验设计、数据支撑、可复现、ablation | 15% | 6 分 |
| 写作清晰度 | 结构完整性、表达流畅、图表规范、引用合规 | 10% | 4 分 |
| 相关工作完整性 | 文献覆盖、对比充分、研究定位 | 10% | 4 分 |

> 说明：SAR 原始总分 ×4 = 自动化打分（40 分），即论文质量总分 60 分中的 40 分（2/3）；其余 20 分官方未明示（推测为技术包/复现/决赛环节）。

## 6. 提交要求

**有效作品硬性条件**：参赛 Agent **必须基于 openJiuwen 社区开源代码开发，必须修改 JiuwenSwarm 源码**，否则视为无效作品。

**提交方式**：所有文件打包为 zip（以团队名称命名，如 `团队名称.zip`）；每日最多 3 次；以每个提交周期最后一次提交为准评测。

**材料清单（4 件）**：
1. **核心成果**：Agent 生成的科研短论文（PDF，符合学术规范）
2. **技术包**：openJiuwen 框架下的 Agent 源码（含注释、工程说明）；运行配置、环境依赖、复现指南；技术文档（架构设计、openJiuwen 模块调用、创新点）
3. **资源报告**：Token 消耗、运行时长、算力日志（可追溯）
4. **框架贡献说明**：代码优化/功能拓展的说明文档 + PR 链接

**开源义务**：获奖选手需把代码开源到 Atomgit（仓库：`https://gitcode.com/openJiuwen/agent-store`）

## 7. 官方推荐解题思路
