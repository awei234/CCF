## 阶段 0：环境就绪（原 W0）

**目标**：JiuwenSwarm 能跑起来，DeepSeek 能调，输出一个最小 demo。

**任务清单**：
1. 安装 Python 3.11+（若已有则跳过）→ 检查 `python --version`
2. 用 `uv` 或 pip 安装 jiuwenswarm（源码位于 `03_技术实现/jiuwenswarm/`，参考 `README_CN.md` 与 `docs/zh/Quickstart.md`）
3. 申请 DeepSeek API key（https://platform.deepseek.com/），充值小额测试金
4. 配置模型接入：JiuwenSwarm 支持 OpenAI 兼容接口 → 在 config 中配置 DeepSeek endpoint
5. 跑通最小 demo：让 agent 完成一次简单任务（如生成一篇 500 词短文），确认全链路 OK
6. 验证 skill 机制：用内置 skill（如 `skill-omni-creation`）触发一次
7. **记录 Token/时长日志** → 存 07_记录/资源日志.md（有消耗即记）

**出口条件**：✅ Agent 能调 DeepSeek 输出内容；✅ 框架 CLI 正常；✅ 知道怎么加 skill / 改 rail

**关联方向**：D01（单 skill 流水线的环境前提）、03_技术实现/环境搭建说明.md

> 状态：服务器主线已完成（08-12），缺口见 `细化_01_阶段执行手册.md` 阶段 0 出口条件。

## 阶段 1：最小闭环（原 W1）

**目标**：用最轻的方式生成第一篇论文，拿到 SAR 基线分。

**任务清单**：
1. 创建科研 skill（v0）：只实现"提示词驱动"版——把 FARS 附录 B 的四阶段 prompt 原文装进 skill
2. 生成第一篇论文：主题选 T01（上下文工程，最容易做对）+ DeepSeek 驱动
3. 输出 PDF（ICLR 模板，模板在 04_论文写作/）
4. 提交 https://paperreview.ai 评测 → 记录 6 维分数到 05_评测与迭代/基线分.md
5. 分析基线：哪里低分？对照 00_比赛总览/评分体系拆解.md

**出口条件**：✅ 有 SAR 基线分数；✅ 知道分数瓶颈在哪

**关联方向**：D01、T01、F01（写作硬校验预研）

**目标**：实现第一批 rail，第二轮结束前提交首版增强方案。
